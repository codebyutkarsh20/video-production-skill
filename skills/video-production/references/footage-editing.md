# Edit existing footage

Use for interviews, talking heads, podcasts, reels and cutdowns: anything cut from recorded media. An agent cannot watch or hear video, so every step turns footage into something readable. Commands run from the project folder, with `VT` standing for `python3 <skill>/scripts/video_tools.py`. Each step ends on its completion check.

1. **Inventory.** List each source's duration, FPS, orientation, audio and rights. Put sources in the project or pass `--source-root` for an explicit outside folder. *Done when every source has a manifest `assets` entry with provenance and rights.*
2. **Transcribe.** `uv run <skill>/scripts/transcribe.py source.mp4 --out words.json --glossary "Acme,Priya"`. Audio stays on this machine. A missing model stops the run; ask the user before rerunning with `--download-model`, since it is a large download. *Done when `words.json` exists for every source with speech.* Without `uv`, install the script's declared dependencies or ask for a supplied transcript in the same JSON shape.
3. **Read.** `VT pack words.json` prints phrases with times and a word count. Words marked `?word?` are low confidence: check names and numbers against the brief or by `VT timeline source.mp4 --start A --end B --out view.png --words words.json`. *Done when the whole transcript is read and every low-confidence word that would appear in the edit is resolved or listed for the user.*
4. **Propose the edit.** Write the hook, the kept ranges with a reason for each, and the ending, using [craft](craft.md). Stop for the user when they asked to review the plan or the edit changes meaning. *Done when each range traces to a source time and the total fits the target length.*
5. **Cut.** `VT cuts --ranges 3.12-3.84,4.76-6.32 --fps 30 --media source.mp4 source.mp4`, then paste the printed scenes into the manifest. Times snap to frames; `--media` also splits at shot changes. Check the options with `VT cuts --help`. *Done when `VT check project.json` passes.*
6. **Reframe when the aspect changes.** Set `"fit": "cover"` on each scene. For faces, run `uv run <skill>/scripts/reframe.py project.json` and read the report, then rerun with `--apply`. The detector is frontal-face only: review scenes with `needs_visual_check` and set `focus_x` by hand from a frame, as with profiles, backs of heads or products. Tracking holds one position per scene and does not pan within a shot. *Done when every cropped scene has a checked `focus_x`.*
7. **Caption.** `VT captions project.json --words source.mp4=words.json --out captions.srt`, then correct the listed uncertain words. Add `"captions"` and `"burn_captions": {"style": "bold-center"}` to the manifest when the picture carries them. *Done when no known transcription error remains.*
8. **Compose and finish.** Add `music` and `loudness` where the brief calls for them. `VT compose project.json out.mp4`. *Done when `technical_pass` is true and each entry in `warnings` is fixed or reported.*
9. **Measure.** `VT verify out.mp4 --manifest project.json --qc --loudness-target -14 --report report.json`. A `fail` exits 1. A `warn` needs a decision: fix it, or keep it and state why. Fast-speech caption warnings often stay, because trimming sentences changes what was said. *Done when no `fail` remains and each `warn` has a decision.*
10. **Self-check.** `VT review out.mp4 --manifest project.json --out review/` makes images of the opening, ending and cuts with waveforms. Read every image and look for chopped words at silent gaps, caption collisions, crops that lose the subject, and jumps across a cut. When it reports views not shown, inspect those with `VT timeline`. Fix what you find, recompose and repeat, up to 3 passes; after that, report what remains. *Done when a pass finds nothing new or the third pass ends.*
11. **Check speech.** `uv run <skill>/scripts/transcribe.py out.mp4 --out out_words.json`, then `VT speech-check out_words.json captions.srt`. Treat a `warn` as a reason to look, since ASR also makes mistakes. *Done when the status is `pass` or the differences are explained.*

Report the states from SKILL.md separately. These tools measure the export and show sampled frames; audible clicks, motion feel and voice quality still need a person to play it.

## Revisions

Map timestamped feedback to scene IDs and change only those scenes. Unchanged scenes reuse their cache. Rerun steps 7–11 when timing changed, because cues are mapped to the output timeline.
