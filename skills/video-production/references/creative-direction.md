# Creative direction, visuals and voice

Use this guide when the brief is vague, a quality improvement is needed, or production depends on choosing assets/tools. Adapt the depth to the request; a caption fix does not need a creative consultation.

## Give the user a useful starting point

An initial recommendation contains:
- A concrete concept and the audience outcome it serves.
- A short description of what appears on screen, the narration/sound style and the ending.
- The strongest missing input or capability, why it matters, and a recommended way to resolve it.
- Work that can start now, plus optional upgrades that materially improve the result.

For example: “For this HR launch, I recommend a problem-to-payoff story: open on a crowded task list, show one real employee update through to its observed result, then close on the logo and next action. Use focused screen crops, restrained motion, captions and warm narration. I can prepare the storyboard and capture now; a voice audition needs either a local speech engine/model or a connected speech service.”

When the user requests the complete short film, an internal test excerpt supports that build. It does not turn the deliverable into preview-only work. Preserve explicit review checkpoints.

## Discover capabilities before requesting connections

Inspect exposed tools, installed executable capabilities and user-supplied project assets. Use tool metadata or normal dependency checks; do not inspect secrets, private personal libraries or unrelated applications. Installed software, automation access, export capability and distribution rights are separate facts. An agent may be unable to operate an installed desktop editor.

Map the current creative need to a route:

| Need | Check locally or already connected | Relevant optional addition |
|---|---|---|
| Authentic product actions | Browser capture, screen recorder, authorized app access | Capture/automation capability or supplied recording |
| Graphics and motion | Existing brand files, fonts, SVG/canvas, FFmpeg, scripting renderer, accessible editor | Design integration, motion editor or licensed template |
| Original still visuals | Supplied photography, diagrams, available image tools | Image generation or licensed stock source |
| Generated movement, avatars or 3D | Available model tools, local GPU/runtime, usable renderer | Video generation, avatar or specialist 3D tool |
| Narration and sound | Supplied recording, microphone access, installed speech engine/model, audio editor | TTS service, local voice model or licensed sound library |
| Captions and localization | Timed script, transcription/alignment and translation capabilities | Alignment/transcription tool or language reviewer |

This is a discovery map, not a supported-provider list. Use current official documentation before recommending specific services, plans, voice catalogs, hardware requirements or setup commands. Existing connectors and purpose-built tools take priority when sufficient. Do not claim a connection or license exists until checked.

Present only additions relevant to the quality gap. For each recommendation explain: the visible/audible improvement, availability here, required input/account/install, likely local versus external processing, known cost or unresolved pricing, and a useful alternative. Rank by expected benefit, effort and constraints; a paid provider is not automatically better. Ask for consequential choices, not a catalog of integrations.

Use the host's supported connection/settings flow. Guide users to configure credentials securely; never request API keys in chat. Obtain authorization before paid use, external uploads, microphone/screen permissions or material environment changes when it is not already granted. Respect existing authorization and avoid repeated approval. Do not silently download large models or activate trials. If blocked, continue script, storyboard, asset preparation or other independent work, while retaining the requested final output as the goal.

## Visual direction

Recommend a coherent visual treatment: composition, typography, palette, pacing, motion, transitions and on-screen hierarchy, anchored to supplied brand/source material. Show a style frame or short motion test when that will resolve uncertainty. Static frames do not establish motion quality.

Prefer actual capture for factual interface demonstrations; generated imagery can support the story but must not invent product behavior. Use legible deterministic overlays for precise text. Preserve continuity, framing, safe areas, readable controls and visual accessibility across exports. Suggest stock, image generation, motion graphics or specialist tools when they address a specific gap. Inspect their actual output before scaling production.

## Voice and audio

Reuse known language, accent, tone and audience preferences. When unspecified, recommend a suitable direction and ask only if the choice materially affects the result. Discover whether a usable TTS engine and voice/model are actually present; OS speech availability alone does not establish redistribution rights or suitability.

Offer a short audition with representative product names and numbers before committing a long narration when voice choice is uncertain. If synthesis is unavailable, offer local setup, a connected service or a human recording with concrete tradeoffs. State which option is executable now. A textual voice description is not an audio audition. An audition is a quality check; it adds a user approval checkpoint only when requested or when a consequential voice choice remains unresolved.

Compare intelligibility, accent suitability, pronunciation, warmth, pacing, expressiveness and usage rights. Avoid promising the “best” voice from a provider name alone. Use a licensed voice; voice cloning requires the speaker's authorization. Keep narration above music, measure actual speech timing, and recheck captions after voice changes. Mark listening coverage honestly.

## Improve without expanding the assignment silently

At relevant checkpoints, surface the most valuable observed improvement with its reason and effect on time/cost. Apply routine reversible improvements within scope; present optional new deliverables separately. When the requested approach fails, diagnose it, preserve completed assets, and propose the closest useful route with the material tradeoffs. Never replace a promised narrated master with a silent work-in-progress without explaining what remains.
